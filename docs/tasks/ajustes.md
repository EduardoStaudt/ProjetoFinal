- t2 linux: CORREÇÃO da explicação do ssl_tlsv1_2 (print 27). "ssl_tlsv1_2" da task é nome inexistente e o parser aborta com "500 OOPS: unrecognised variable in config file". Não é que a versão não suporte TLS 1.2. O man diz que ssl_tlsv1=YES PERMITE TLS 1.0, mas o openssl s_client -starttls ftp com -tls1 e -tls1_1 (cliente em SECLEVEL=0) recebe "tlsv1 alert protocol version" (alerta 70), e -tls1_2/-tls1_3 conectam. Quem barra TLS < 1.2 é a libssl3 do Ubuntu (OpenSSL 3.0.13, patch tls1.2-min-seclevel2: no SECLEVEL 2 padrão, TLS 1.0/1.1 ficam desligados), não o vsftpd.conf.
